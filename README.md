# Lampa Player — плагин для Lampa

Плагин связывает [Lampa](https://github.com/yumata/lampa-source) с iOS-плеером «Lampa Player» (mpv, PiP, HDR, встроенный TorrServer).

## Подключение

1. Lampa → Настройки → Расширения → Добавить плагин:

   ```
   https://lardan099.github.io/lampa-player-plugin/lampa-player.js
   ```

2. Настройки → Плеер → тип плеера **Infuse** (и для торрентов тоже).

## Что делает

- Когда Lampa открывает видео во «внешнем плеере», плагин передаёт в Lampa Player серии сезона, **все** субтитры, метки пропуска заставок и рекламы, превью кадров, позицию и ключ отметки просмотра. Работает и для онлайна, и для торрентов.
- Когда вы возвращаетесь в Lampa, плагин забирает у плеера позиции просмотра (`http://127.0.0.1:8090/lampaplayer/progress`) и ставит отметки в Lampa, в том числе с синхронизацией в аккаунт.

Плагин работает только на iPhone и iPad. На остальных устройствах он ничего не делает.
